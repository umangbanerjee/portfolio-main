# portfolio-main

The personal portfolio and product case studies of **Umang Banerjee** — Product Thinker & Technology Builder.

Built with **Next.js 15 (App Router)**, **React 19**, **TypeScript**, **Tailwind CSS**, and **GSAP**.

## Shipped Case Studies
1. **LifeTrack Pro**: Unified life management platform on Google Play Store.
2. **MarketFlow**: Autonomous marketplace intelligence & Gemini causal AI investigation engine.
3. **RailKhoj**: Real-time train intelligence and live GPS telemetry platform.
4. **OneTrack**: Search command center, real-time salary benchmarks & job tracking platform.
5. **GateWise**: Enterprise campus exit-pass & security attendance management system for Starex University.
6. **Unniverse**: Student-centric community platform and AI resume builder (1,500+ students, ₹3.5L revenue).

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.
